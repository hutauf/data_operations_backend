# ⚠️ Veraltet / Deprecated

**Dieses Repository wird nicht mehr gepflegt.** Der Code hier (`flask_app.py`) ist ein alter Stand des Sync-Backends für taxsummary (VineTaxTools) und den Vine Produkt Manager.

**Aktuelle Anleitung und aktuelle Datei:** <https://hutauf.org/selbst-hosten/>

Dort gibt es die gepflegte `self_hosted_backend.py` zum Herunterladen und die Schritt-für-Schritt-Anleitung zum Einrichten (z. B. auf PythonAnywhere), zum Verbinden der Werkzeuge und zum Aktualisieren.

Wer dieses alte Backend noch betreibt: vor dem Umstieg den Ordner `user_databases` sichern. Die neue Version übernimmt bestehende Datenbanken beim ersten Start automatisch und legt dabei Sicherungen an (Details auf der Seite oben).
